# ⚙️ Prerequisites

Before running the projects/examples:

- Java 17+
- Maven Installed
- MySQL Installed
- STS / IntelliJ IDEA

---

# ▶️ Clone Repository

```bash
git clone https://github.com/abhishekkargeti1/Java-Spring-Notes.git
```

---

# ▶️ Run The Project

Navigate to the desired project folder and run:

```bash
mvn clean install
```

Or run the application directly from STS / IntelliJ IDEA.

---

# 🔑 Database Configuration

Update database credentials inside:

```properties
application.properties
```

Example:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/database_name
spring.datasource.username=root
spring.datasource.password=your_password

spring.jpa.hibernate.ddl-auto=update
```
